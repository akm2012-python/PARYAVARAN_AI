🚀 All 21 Signature Features

Combining Explainable AI (XAI), Ternary logic hardware control, sensorless predictive analytics, and automated research utilities.

1. GreenExplain XAI™

Provides human-readable explanations and explicit feature deductions alongside every operational system state.

2. TriLogic Engine™

Implements ternary state logic (-1: Alert, 0: Balanced, +1: Eco Mode) displayed physically through traffic LEDs.

3. EcoPredict AI™

Estimates continuous energy usage, power conservation ratios, and carbon offsets without hardware current meters.

4. AirGuardian AI™

Monitors ambient hazardous gas concentrations using MQ-135 sensors, triggering automated mitigation alerts.

5. EcoTwin™ Simulator

An interactive digital twin allowing real-time parameter adjustments and 'What-If' scenario evaluations.

6. TinyML Embedded Layer

Lightweight execution optimized for deployment directly on low-power microcontrollers like Arduino UNO.

7. AI Energy Efficiency Meter

Computes mathematical power profiles based on real-time active load dynamics and peripheral state draws.

8. Environmental Health Index (EHI)

Fuses multi-sensor air, temperature, and cleanliness telemetry into a single comprehensive safety score.

9. Passenger Density Predictor

Utilizes IR beam patterns to calculate real-time bus stand occupancy and seating demand dynamics.

10. Predictive Energy Forecasting

Anticipates power consumption curves using machine learning models trained on ambient historical trends.

11. Automated ML Dataset Generator

Continuously archives calibrated sensor readings into organized, research-grade CSV datasets automatically.

12. Live Telemetry Dashboard

A responsive UI built with Streamlit and Plotly for real-time sensor monitoring and visual gauge updates.

13. Smart Waste Level Sensing

Uses ultrasonic HC-SR04 sensors to monitor dustbin fill percentages and issue maintenance alerts.

14. Adaptive Ambient Lighting

Adjusts bus shelter illumination based on LDR ambient light levels to optimize energy usage.

15. Real-Time Fault Diagnostics

Monitors hardware sensor integrity continuously to detect missing or corrupted telemetry streams.

16. Carbon Footprint Estimator

Translates energy savings directly into estimated carbon emission reductions ($CO_2$ offsets).

17. High-Speed Serial Bridge

Handles zero-latency serial streaming from microcontrollers using PySerial data pipelines.

18. Model Benchmarking Suite

Runs automated performance comparisons across Scikit-Learn regression models for continuous validation.

19. Autonomous Climate Control

Activates cooling fans based on real-time temperature and humidity thresholds from DHT11 sensors.

20. Virtual Sensor Override

Allows manual override of sensor inputs during live testing and exhibition scenarios.

21. Zero-Cloud Local Inference

Runs all core logic and AI inference locally on the edge, ensuring operational independence without cloud requirements.
