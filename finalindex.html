⚙️ System Architecture

Comprehensive hardware, machine learning, and hardware-free estimation stack driving zero-latency decision intelligence.

Hardware Layer

Sensor & Actuator Stack

  • Microcontroller: Arduino UNO Board
  • DHT11: Ambient Temperature & Humidity
  • MQ-135: Hazardous Gas & Air Quality PPM
  • HC-SR04: Ultrasonic Dustbin Height Sensor
  • IR Sensor: Passenger Density Telemetry
  • LDR Module: Day/Night Light Intensity
  • Control Relays: Smart Fan & Lighting Loops
Software Stack

AI & Analytics Core

  • Python 3.10+: Core Analytical Framework
  • Streamlit Framework: Real-Time Dashboard
  • Scikit-Learn: Model Comparison Engine
  • Plotly Graphics: Interactive Gauges
  • PySerial: USB Communication Bridge
  • Auto Data Logger: Continuous CSV Archiving

🚀 Core Features

🧠 GreenExplain XAI™

Never shows just a raw number. Every system decision is accompanied by human-readable explanations and explicit feature deductions.

🔺 TriLogic Engine™

Transitions beyond binary logic into a ternary framework (-1: Alert, 0: Balanced, +1: Eco Mode) rendered via physical traffic lights.

⚡ EcoPredict AI™

Estimates continuous energy usage, power conservation ratios, and projected carbon emission offsets without requiring external hardware sensors.

🌟 24 Signature AI Innovations

Specialized features engineered specifically to stand out during exhibition evaluation.

Explainable AI (XAI)

Transparent real-time point-by-point breakdown showing exactly why optimization scores change.

Virtual Energy Meter

Calculates active wattage and power savings mathematically without requiring extra INA219 chips.

Environmental Health Index

Synthesizes DHT11 temperature, humidity, and air metrics into a single 0–100 public safety score.

Passenger Density Predictor

Evaluates IR state history to classify and forecast low, medium, or high upcoming congestion.

Waste Collection Forecast

Calculates bin volume fill rates using HC-SR04 telemetry to schedule timely municipal dispatch.

ML Model Comparison

Evaluates Decision Trees, Random Forests, KNN, and SVR live on Streamlit to select optimal model logic.
