# EcoSmart AI Bus Stand - Required Libraries

This project requires specific Arduino libraries and Python packages for compilation and dashboard operation.

---

## 🤖 Arduino Libraries

Install these libraries via the **Arduino IDE Library Manager** (`Sketch -> Include Library -> Manage Libraries...`):

1. **DHT sensor library** (by Adafruit)
   * Version: `1.4.6` or higher
2. **Adafruit Unified Sensor** (by Adafruit)
   * Version: `1.1.14` or higher

---

## 🐍 Python Environment Requirements

Install all necessary Python dependencies using `pip`:

```bash
pip install -r requirements.txt
